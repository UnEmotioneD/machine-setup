## Install Packages

- `i3`: the window manager
  - `i3lock`: lock screen
  - `i3status`: statusbar
  - `dmenu`: app launcher
- `alacritty`: i3 sensible terminal
- `feh`: wallpaper
- `picom`: compositor (fixes screen tearing)
- `playerctl`: media control

```sh
sudo apt install -y i3 alacritty feh picom playerctl
```

## Start i3wm

Logout and log back into select `i3`.

```sh
# logout from i3
i3-msg exit
```

## Mouse sensitivity

To change mouse sensitivity create config file

```sh
sudo -E nvim /etc/X11/xorg.conf.d/40-mouse.conf
```

Just put this in there and reboot

Reference: 10cm from edge to edge on QHD monitor

```conf
Section "InputClass"
    Identifier "Disable accel and slow mouse"
    MatchIsPointer "on"
    Driver "libinput"
    Option "AccelProfile" "flat"
    Option "AccelSpeed" "-0.13"
EndSection
```

## Key Repeat

- delay: 250ms
- repeat speed: 70 frequency

```conf
exec_always --no-startup-id xset r rate 250 70
```

## Dmenu

From `dmenu_run` to `i3-dmenu-desktop` to only shows desktop app

```conf
bindsym Mod1+space exec --no-startup-id i3-dmenu-desktop
```

## Status Bar

Copy default config to `~/.config/i3status`

```sh
mkdir -p ~/.config/i3status
cp /etc/i3status.conf ~/.config/i3status/config
```

---

## Wallpaper

Set it with `feh` on login.

```conf
exec_always --no-startup-id feh --bg-scale {absolute path to the image}
```

## Monitor Setting

```sh
# show monitor information
xrandr -q

# monitor settings for the output
xrandr --output DP-4 --mode 2560x1440 --rate 239.97
```

### Dual monitor

Secondary monitor position with `--left-of` option.

```sh
xrandr --output eDP-1 --mode 2560x1440 --rate 239.97 --output HDMI-1 --mode 1920x1080 --rate 60.00 --left-of eDP-1
```

### Xrandr On Login

Inside `~/.config/i3/config` add the following line:

```conf
exec_always --no-startup-id xrandr --output eDP-1 --mode 2560x1440 --rate 239.97 --output HDMI-1 --mode 1920x1080 --rate 60.00 --left-of eDP-1
```
