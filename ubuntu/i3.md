## Install Packages

- `i3`: the window manager
  - `i3lock`: lock screen
  - `i3status`: status bar
  - `dmenu`: app launcher
- `alacritty`: i3 sensible terminal
- `feh`: wallpaper
- `picom`: compositor (fixes screen tearing)
- `playerctl`: media control
- `pavucontrol`: media control GUI

```sh
sudo apt install -y i3 alacritty feh picom playerctl pavucontrol
```

## Start i3wm

Logout and log back into `i3`.

> [!TIP]
> To log out from i3, enter `i3-msg exit` in the terminal.

---

## Key Repeat

- delay: `250ms`
- repeat speed: `70` frequency

```conf
exec_always --no-startup-id xset r rate 250 70
```

---

## Dmenu

Change from `dmenu_run` to `i3-dmenu-desktop` to only show desktop apps:

```conf
bindsym Mod1+space exec --no-startup-id i3-dmenu-desktop
```

---

## Wallpaper

Set it with `feh` on login.

```conf
exec_always --no-startup-id feh --bg-scale <absolute-path-to-img>
```

## Monitor Setting

```sh
# show monitor information
xrandr -q

# monitor settings for the output
xrandr --output DP-4 --mode 2560x1440 --rate 239.97
```

### Dual monitor

Secondary monitor position with the `--left-of` option.

```sh
xrandr --output eDP-1 --mode 2560x1440 --rate 239.97 --output HDMI-1 --mode 1920x1080 --rate 60.00 --left-of eDP-1
```

### Xrandr On Login

Inside `~/.config/i3/config` add the following line:

```conf
exec_always --no-startup-id xrandr --output eDP-1 --mode 2560x1440 --rate 239.97 --output HDMI-1 --mode 1920x1080 --rate 60.00 --left-of eDP-1
```
